# Karpathy Human Comprehension Skills

[English](README.md) | **简体中文**

让复杂的智能体工作结果更容易理解和审阅。

智能体完成任务后，你往往还需要弄清楚：改了什么，各部分如何相互影响，结论是否有证据支持。`human-comprehension` 是一份 Markdown 技能，帮助智能体把这些信息讲清楚，让你能够核查结果。

它优先使用简洁文字，在确有帮助时补充表格或图示，同时保留证据、不确定性和实际验证范围。

## 适合哪些场景

当你需要理解关键关系才能判断结果时，可以使用这个技能：

- **审阅代码改动：** 说明各项修改如何配合，以及实际检查了什么。
- **理解调试结论：** 交代观察结果与结论的联系，区分可能原因和已确认原因。
- **梳理系统架构：** 展示需要核查的依赖关系、分支或状态转换。
- **比较方案：** 对齐比较维度，明确哪些信息是估计、哪些证据尚缺。
- **接手未完成的工作：** 说明已完成部分、阻塞点和仍未验证的内容。

简单修改可能一句话就够；单个文件中的复杂交互也可能需要图示。表达方式取决于读者需要理解什么，而不是文件数量或回答长度。

## 安装

克隆仓库，或从 GitHub 下载：

```sh
git clone https://github.com/OpenQwert/karpathy-human-comprehension-skills.git
```

将完整的 `skills/human-comprehension` 文件夹复制或链接到对应智能体的技能目录：

| 智能体 | 个人技能安装路径 | 显式调用方式 |
| --- | --- | --- |
| Codex | `~/.agents/skills/human-comprehension/` | `$human-comprehension` |
| Claude Code | `~/.claude/skills/human-comprehension/` | `/human-comprehension` |

`~` 表示你的用户主目录。请保留 `SKILL.md` 和 `references/diagram-guidelines.md` 的目录关系，技能会在需要画图时读取参考文档。只复制 `SKILL.md` 会导致该参考文档不可用。

两种智能体的官方文档均说明支持链接形式的技能文件夹。技能发现与配置方式请参阅 [Codex 官方文档](https://learn.chatgpt.com/docs/build-skills)和 [Claude Code 官方文档](https://code.claude.com/docs/en/skills)。其他智能体请按其宿主文档确定技能目录与加载方式。

## 使用示例

在 Codex 中：

```text
$human-comprehension
解释这些修改如何相互配合，提供可核查的证据，并说明实际验证了哪些内容。
```

在 Claude Code 中：

```text
/human-comprehension 解释这些修改如何相互配合，提供可核查的证据，并说明实际验证了哪些内容。
```

你也可以指定表达形式和详略：

```text
用表格比较这三个方案，明确标出估计值和未知信息。
```

```text
用简短的纯文本解释重试与失败分支，并说明哪些测试没有运行。
```

技能会遵守你的语言和呈现偏好。显式调用不意味着必须画图或创建文件；能否自动调用取决于智能体的技能支持和配置。

## 工作方式

技能使用任务中已有的改动、源材料、工具输出、计算和验证记录，根据审阅需要选择表达形式：

| 你需要做什么 | 适合的表达形式 |
| --- | --- |
| 理解结果、条件或下一步操作 | 简洁文字或短步骤 |
| 比较方案、属性或证据情况 | 紧凑表格 |
| 跟踪交互、分支或状态转换 | 简短说明配合聚焦关键关系的图示 |
| 审阅证据不完整的结论 | 明确限定条件的文字，仅展示有依据的关系 |

这些形式可以组合使用。如果宿主无法渲染图示，或渲染能力未知，技能会用文字、表格或简单文本图保留可读性。

交付前，技能会检查表达是否忠实于已有证据：数字与单位、标识符、关系含义、完成状态、不确定性，以及实际检查的覆盖范围。文字、表格和图示之间应保持一致。

**检查说明是否忠实于证据，不能替代对任务本身的验证。** “修改已经写好”不能变成“行为已经测试通过”；“两件事先后发生”也不能变成“前者导致后者”。

## 首版范围与验证

v0.1 的技能本体只有两个文件：

```text
skills/human-comprehension/
├── SKILL.md
└── references/
    └── diagram-guidelines.md
```

它向智能体提供行为指引，不包含安装器、独立的事实核验运行时或宿主专用适配器。v0.1 不自动生成 HTML 或视频。

技能已通过格式验证。一次显式加载技能的试用中，独立智能体处理了十个合成场景；随后按 v0.1 设计审阅，十份输出均通过本次检查。[验证报告](docs/validation-report.md)记录了完整输入、输出和审阅边界。

这些检查不能证明宿主会自动发现技能、各宿主端到端兼容，或真实用户的理解效果已有改善。本轮试用也未渲染并目视检查 Mermaid 图示。
